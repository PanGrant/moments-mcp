# moments-mcp — 让 Claude 帮你逛朋友圈、回评论

你在 Mac 上用微信。装上这个工具后，你可以直接跟 Claude 说：

> "帮我看看今天朋友圈有什么。"
> "都回一下吧。"

Claude 会替你翻一遍朋友圈（只用下翻键，像你自己刷一样），把今天能回的
帖子列给你看；你点头之后，它才以你的账号**真实发表评论**。每条评论
自动带一句署名，声明这是 AI 自动内容：

> AI助手胡乱解读自动回复，内容请忽略

⚠️ **发出去的评论公开可见，无法自动撤回**；通过 GUI 自动化操作微信可
能不符合微信的使用条款，账号风险请自行评估。完整警示见
[INSTALL.md](INSTALL.md) 开头。

## 它守的规矩

- **先给你看，再动手**：默认模式只翻不评；要发评论必须你在场明确同意
  （工具层面强制，Claude 想绕也绕不过）。
- **只回 24 小时内的帖子**，翻到"昨天"就停。
- **不回自己**：把你微信上的名字填进配置，自己的帖子直接跳过。
- **广告不回**（作者行右侧带下拉箭头的推广帖，自动识别跳过）。
- **看不懂的不硬回**：正文文字太少的帖子跳过，不编。
- **回过的不再回**：它有账本（就在你自己电脑上），同一条不会回两次。

## 你需要准备什么

一台 Mac（装好并登录微信）+ 一个 AI 大模型的 API 钥匙（类似给
Claude/智谱这类服务的付费钥匙）。全程不需要任何云服务账号——识别
帖子用的文字识别就在你电脑上运行。

**安装只要十几分钟**：[INSTALL.md](INSTALL.md) 手把手带你走完
（权限 → 钥匙 → 接入 Claude → 第一次只看不评的试跑）。

## 装好之后怎么用

跟 Claude 正常说话就行，比如：

| 你说 | Claude 做什么 |
|---|---|
| "看看今天朋友圈" | 只翻不评，翻完给你列帖子清单 |
| "帮我回复今天的朋友圈" | 先给你看它的回复风格设置，你确认后真实发评论 |
| "停一下" | 立即停止翻阅 |
| "回过哪些了？" | 报告账本：哪些回了、哪些跳过、为什么 |

评论的语气可以定制（比如"像老朋友随手写的"或"简洁克制"），也可以
补充要求（"别用 emoji"），用 `moments_settings_set` 或直接编辑一个
本机设置文件，见 INSTALL.md。

## 你的数据在哪

全在你自己电脑上：翻阅记录、账本、设置都在本机文件里，不上传。
唯一出网的时刻是生成评论文字时，会把帖子文字发给你配置的那个 AI 服务。
只翻不评的模式全程不联网。
